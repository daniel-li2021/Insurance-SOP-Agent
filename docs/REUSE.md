# Open-source research and reuse

Reviewed October 16, 2026 using live GitHub repository metadata and primary documentation. Stars are a discovery signal, not proof of correctness. Scope stays one React/FastAPI application.

- [shadcn/ui](https://github.com/shadcn-ui/ui): 125,732 stars, MIT. Adapt its small Button variant pattern and design tokens; retain the license notice for adapted code. Avoid generating an entire dashboard.
- [Radix Primitives](https://github.com/radix-ui/primitives): 19,399 stars, MIT. Reuse the packaged Dialog and Tabs primitives for keyboard navigation, focus trapping/restoration, and mobile inspector behavior. [Dialog documentation](https://www.radix-ui.com/primitives/docs/components/dialog).
- [assistant-ui](https://github.com/assistant-ui/assistant-ui): 12,571 stars, MIT. Reference externally owned chat state, explicit running/error state, composer recovery, and scrolling. Its [external store contract](https://www.assistant-ui.com/docs/api-reference/external-store/runtime) supports this architecture, but importing a second conversation runtime is unnecessary for the bounded JSON API. No source copied.
- [FastAPI full-stack template](https://github.com/fastapi/full-stack-fastapi-template): 46,001 stars, MIT. Reference environment validation, test dependency overrides, React/Vite separation, and Docker packaging. Do not import account management, Postgres, email reset, or generated admin screens. No source copied.
- [Vercel chatbot](https://github.com/vercel/chatbot): 20,996 stars. Inspected root license: Apache-2.0 terms (GitHub metadata reported NOASSERTION). Reference conversation hierarchy, input persistence, suggested starts, and follow-to-bottom interaction; do not import Next.js, AI Gateway, artifacts, auth, or streaming/tool execution. No source copied.
- [Promptfoo](https://github.com/promptfoo/promptfoo): 26,040 stars, root MIT license. Reference [deterministic assertions versus model-graded metrics](https://www.promptfoo.dev/docs/configuration/expected-outputs/), expected/observed comparison, and replayable results. Implement a small pytest-backed scenario runner shared with the UI, rather than installing a second evaluation stack. No source copied; individual enterprise modules require separate license consideration if ever adopted.
- [DeepEval](https://github.com/confident-ai/deepeval): 18,900 stars, Apache-2.0. Reference separation of conversational quality and hard assertions. Defer dependency and judge-model calls until a larger quality corpus warrants them. No source copied.
- [Chainlit](https://github.com/Chainlit/chainlit): 12,519 stars, Apache-2.0. Considered Python-first chat scaffolding; rejected because its application runtime and frontend conventions would complicate the bespoke inspector and Evaluation Lab. No source copied.

Implementation remains incremental: controller and guarded access tests → early chat/inspector → live structured interpretation → consent/recovery → shared Evaluation Lab → Docker and browser verification. The accepted proposal remains the SOP contract. Actual UI components and dependencies are tracked in the frontend lockfile; adapted source retains attribution in THIRD_PARTY_NOTICES.md.
