## Required fidelity surfaces

- **Typography:** retained the current Inter/system font stack, readable message size/line height, and existing weights. Tightened heading and label spacing. Standard mode retains explanatory text; expanded mode hides secondary header copy. Narrow assistant subtitles truncate within the existing header instead of overflowing.
- **Spacing/layout:** retained navigation, workflow rail, conversation, inspector, and fixed composer. Standard mode offers three scenario cards on desktop and a compact picker on narrow screens. Expanded mode narrows the workflow rail and inspector, compresses controls, and hides the repeated welcome once messages exist. The message viewport gains more than 40 CSS pixels at all five tested sizes.
- **Colors/tokens:** retained ClaimFlow's muted green accent, neutral surfaces, borders, semantic verification colors, and existing button styles. Added only restrained card outlines, pill borders, and panel shadow.
- **Assets:** retained the supplied ClaimFlow brand treatment and installed Lucide icons. No new raster art, fabricated screenshots, or decorative assets were needed. Published screenshots are sharp native browser captures.
- **Copy/content:** retained real fixture facts, privacy/authorization framing, expired-deadline wording, and explicit simulated Send/Skip controls. Suggestions fill drafts rather than executing requests. The form stays a collapsed optional section by default, an intentional adaptation to reduce vertical cost. Once verified, its trigger disappears under the existing verification-state rule.
